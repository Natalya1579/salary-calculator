# Калькулятор реальных зарплат

## Описание проекта
Сервис позволяет узнать, сколько на самом деле платят специалистам вашего профиля.  
- Все данные добавляются реальными пользователями 
- Можно подписываться на авторов
- Можно добавлять профессии в избранное и следить за обновлениями в подписках.  

**Проблема, которую решает проект:**   
- люди не знают реальную рыночную зарплату по своей профессии и городу,  
- боятся, что их обманывают на собеседованиях  
- сервис позволяет увидеть  

## Возможности  
- Просмотр статистики по профессиям (средняя, мин, макс зарплата)  
- Добавление анонимных отчётов о зарплате  
- Добавление профессий в избранное  
- Подписка на авторов, которые публикуют полезные данные  
- Лента подписок с новыми отчётами  
- Регистрация и вход (с хэшированием паролей)  


## Технологии   
- Python   
- Flask (веб-фреймворк)    
- SQLite (база данных)  


## Установка и запуск  

1. **Клонировать репозиторий**   

`git@github.com:Natalya1579/salary-calculator.git`  
   
2. **Перейти в папку проекта**   

`cd salary-calculator`  

3. **Создать виртуальное окружение**    

Linux/macOS:   

`python3 -m venv venv`  
   
Windows:   

`python -m venv venv`   

4. **Активировать вирутальное окружение**   

Linux/macOS  

`source venv/bin/activate`  
   
Windows  

`source venv/scripts/activate`  

5. **Обновить менеджер пакетов pip**  

`python3 -m pip install --upgrade pip`  

6. **Установить библиотеки из списка зависимостей**  

`pip install -r requirements.txt`  

7. Запустить сервер  

`python app.py`   

## Использование    

Сервер запустится по адресу `http://127.0.0.1:5000/`  

**Первый запуск**  
1. Откройте http://127.0.0.1:5000/  
2. Зарегистрируйтесь (кнопка "Регистрация" в навигации)  
3. Войдите в систему  

**Добавление данных**  
1. Нажмите "Добавить зарплату" в навигации  
2. Укажите профессию, город и зарплату
3. После отправки вы увидите страницу профессии со статистикой  

**Избранное**  
1. На странице любой профессии нажмите "В избранное"
2. Все сохранённые профессии появятся в разделе "Избранное"

**Подписки**  
* На странице профессии есть кнопка [Подписаться]
* Новые отчёты от авторов, на которых вы подписались, появятся в разделе "Подписки"
